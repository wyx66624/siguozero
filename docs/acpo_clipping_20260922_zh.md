# expand 四暗：恢复 ACPO 的逐样本平滑裁剪

2026-09-22，按用户要求恢复 [ACPO 第 3.2 节公式 4–6](https://arxiv.org/html/2510.00690v1#S3.SS2)
的优势感知裁剪形式：使用带正负号的优势调整上界，下界对当轮所有样本相同。
关闭 `absolute_advantage`，将 `unclipped_advantage_threshold` 设为 0，取消 `|A| >= 2` 跳过裁剪的例外。

本次恢复的是逐样本裁剪规则。按训练进度收窄上下界基准的现有日程继续保留，它是本项目的日程，
不是 ACPO 原文的样本复用课程。训练仍使用现有 MAPPO 优势、Critic 和固定 0.01 熵项。

对整轮可学习样本归一化后的优势 A，实际计算为：

```text
q(A) = 0.5 * (1 + erf(A / sqrt(2)))
epsilon_high(A, p) = clamp(b(p) + 0.5 * b(p) * q(A), 0.10, 0.45)
epsilon_low(p) = clamp(l(p), 0.10, 0.45)
r = pi_new(a|s) / pi_rollout(a|s)

L_policy = -mean(min(r*A, clip(r, 1-epsilon_low, 1+epsilon_high)*A))
L_actor  = L_policy - 0.01 * mean(H(pi))
```

正优势越大，上界平滑变宽并饱和于有限上限；负优势采用带符号的映射，不再按绝对值放宽下界。
所有样本均使用同一个 clipped surrogate 形式，没有优势阈值豁免。
裁剪约束的是 surrogate 中继续改善动作的收益，不能解释为概率比更新后必然落在区间内；
朝错误方向变化的样本仍有纠正梯度，熵梯度也单独存在。

`clipping.py` 已有对应功能，正式切换只需要修改两个配置字段。普通 Actor 计算、CUDA 学习图和
最终 KL/clip 探针都读取同一组配置；保留旧可选分支是为了兼容其他实验配置，不会在此训练中启用。
监控面板显示带符号 `erf` 上界、统一下界和所有样本保留裁剪的说明。

测试覆盖生产配置在多个训练阶段的公式数值、优势 ±2 附近连续性、极端正负优势的裁剪梯度、
错误方向的纠正梯度、学习图和普通路径的损失/梯度一致性，以及从旧豁免检查点恢复后采用新规则。
恢复测试同时检查模型、优化器和累计步数保持一致。

操作和实际训练证据保存于 `output/diagnostics/acpo_clipping_20260922/`。
