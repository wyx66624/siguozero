# 已知非军旗大本营的个人处罚

当前 expand MAPPO 新增固定 `known_nonflag_hq_penalty: 0.2`，实际奖励为 **−0.2**，不随训练进度衰减。

行动前，行动者已经通过公开亮旗或公开身份推断知道该方军旗位于另一处大本营时，下列己方棋子主动进入或攻击非旗大本营，扣行动者 0.2：

- 团长、旅长、师长、军长、司令。
- 工兵、炸弹。

军旗尚未知时不罚。吃真旗不罚；营长、连长、排长不适用。判定只使用行动前的己方信息和公开知识，不使用本次交战之后才揭示的身份。司令在这次攻击中才阵亡、从而事后亮旗，不追溯处罚这一步。

攻击失败、撞雷或同归于尽也算此次进攻，会扣分；不要求棋子最终存活在大本营。空的大本营同样按已知旗位判断，自己的旗位本来就已知。处罚是一次性的行动奖励，只扣行动者，未参与行动的队友不连带扣分；不改变规则胜负、合法动作、Actor 观察或布阵回报。
