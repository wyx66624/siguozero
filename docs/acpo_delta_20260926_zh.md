# ACPO 固定基准与优势自适应裁剪

2026-09-26，按用户要求采用 ACPO 的优势裁剪形式，删除 expand 四国暗棋原有的进度收窄日程和 ε 的 `0.10～0.45` 额外限幅。用户确认使用项目既有 PPO 数值作为两个固定基准：`epsilon_low=0.20`、`epsilon_high_base=0.20`；优势放宽量固定为 `delta=0.05`。

依据 [ACPO 原文第 3.2 节式 4–6、Table 3](https://arxiv.org/html/2510.00690v1)：

```text
A = 当前全局归一化后的带符号 PPO 优势
F(A) = 0.5 * (1 + erf(A / sqrt(2)))
epsilon_high(A) = 0.20 + 0.05 * F(A)
ratio_clip = [0.80, 1.20 + 0.05 * F(A)]
objective = min(ratio * A, clip(ratio, ratio_clip) * A)
```

论文所测 `δ = 0.03 / 0.05 / 0.10` 中，`0.05` 平均成绩最高。论文未披露两个基准的明确实验数值，因此 `0.20 / 0.20` 来自用户确认的项目参数，不能称为论文公布的基准。本次对齐 AAAC 裁剪形式和已公布的 δ；不引入 ACPO 针对视觉语言模型的课程采样与复用机制。

| 带符号优势 A | 概率比下界 | 概率比上界 |
| --- | ---: | ---: |
| -2 | 0.80000 | 1.20114 |
| 0 | 0.80000 | 1.22500 |
| +2 | 0.80000 | 1.24886 |
| +∞ 极限 | 0.80000 | 1.25000 |

这些边界不随环境步数变化。没有按优势绝对值放宽下界，也没有大优势免裁剪。上界由公式自身给出；不会再应用项目的 `[0.10, 0.45]` ε 限幅。PPO 裁剪限制目标函数中的改善收益，并不硬性投影更新后的动作概率。
