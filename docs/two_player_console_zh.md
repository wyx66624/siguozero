# 双人军棋专用可视化

双人军棋使用独立控制台配置 `configs/two_player_console.json`，默认端口 **8767**。
控制台仅读取 `runs_expand_mappo/two_player/with_dead_rules`，与四暗的运行目录和端口分开。

## 页面功能

- 训练监控：环境步、保存进度、胜负和、Actor/Critic 损失、KL、学习率、ACPO 裁剪、选子/动作熵及历史对手。
- 对弈室：南北两席、60 点棋盘，支持选择双人模型版本、出招温度、AI 行棋间隔和合法着法高亮。
- 复盘：保留结束棋局的明棋回放，可拖动进度、逐步或自动播放、导出棋谱。

模型通过独立 CPU 进程加载，每局固定开局时的版本。布阵温度仍为 0.3；出招温度只影响人机对弈中的行棋。
浏览器的双人会话、复盘与行棋间隔偏好使用独立存储键。双人页面不会选择四人模型，也不显示队友席位。
训练指标与对弈逻辑复用现有四国控制台，双人展示单独适配。

尚未训练时，页面显示明确标注的预定配置：ACPO + MAPPO、30 亿环境步预算、2500 万步保存、
5 亿步启用历史对手、终局奖励 +1/-1/-0.15。此时不生成指标或可用模型，开局按钮等待首个快照。
实际运行生成 `resolved_config.json` 后，页面完整采用保存的配置，而不将预定值补入实际配置。
历史对手表只显示当前自对弈和历史对手；独立评测采用两局换边口径。

## 后续手动启动

```bash
# 项目根目录，WSL
bash scripts/start_two_player_console.sh

# 或使用已安装项目依赖的 Python
python tools/two_player_console.py

# 需要时指定其他端口
python tools/two_player_console.py --port 8768
```

启动后访问 `http://localhost:8767/` 查看监控，`http://localhost:8767/play` 进入双人对弈室。
入口只启动网页服务，不启动训练，不安装常驻服务，也不改写四国控制台的服务元数据。
终端关闭后服务随之退出；控制台日志和统计缓存位于 `output/two_player_console`。
