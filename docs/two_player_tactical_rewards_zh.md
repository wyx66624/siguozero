# 双人军棋炸大子与守旗奖励

双人 expand MAPPO 的终局胜、负、和基础奖励仍为 `+1 / -1 / -0.15`。
以下即时奖励叠加进入对应玩家的 GAE 和 Critic 目标，不改变棋局胜负判定。

| 事件 | 奖励 |
| --- | ---: |
| 炸司令 | +0.03 × 衰减系数 |
| 炸军长 | +0.01 × 衰减系数 |
| 炸师长 | +0.003 × 衰减系数 |
| 有可行吃子解围动作，却未移除直接夺旗威胁 | -0.1 |
| 成功移除直接夺旗威胁，军旗仍在且没有其他已确认的直接威胁 | +0.05 |

炸大子沿用四人模式的同一实现：按实际兑掉的棋子计分，主动炸、被对方撞炸
都只给炸弹拥有者记一次。衰减系数为 `max(0, 1 - 累计环境步数 / 15亿)`，
以当前 30 亿步预算计算。守旗奖励固定，不随训练步数衰减。

守旗不要求使用最大子力。小子吃子、同级兑子和炸弹兑子都可以。奖励判定只通过
训练奖励通道传递，不写入 Actor 观察或棋局历史。

具体判定：

- 威胁是行动前根据玩家已知身份/公开候选，可以确认下一步直接吃旗的敌子。
  只是在军旗附近、被挡住或无法移动的棋子不算威胁；己方棋子也不算。
- 扣分要求行动前至少有一个合法动作，按所有公开候选都能吃掉或兑掉威胁。
  无子可解围、或者隐藏身份使解围结果无法确认时，不因隐藏真相而扣分。
- 实际成功解除直接威胁记 +0.05；如果同时有多个直接威胁，需要全部解除。
  已经吃掉一个威胁但还有另一个时，既不发成功奖励，也不扣“没去吃”的分。
- 面对威胁直接取得终局胜利也算成功。失败攻击在本来有可行解围动作时扣分。
- 每次行动只判一次；冻结的历史对手行动不获得守旗塑形奖励。
  终局奖励、炸大子奖励与守旗奖励可以叠加，例如炸军长守旗为
  `+0.05 + 当前炸军长系数`。

从没有这些奖励的断点续训，需要显式使用
`--adopt-bomb-rewards --adopt-flag-defense-rewards`。
迁移保留 Actor、Critic、布局模型、优化器、RNG、未完成对局和累计步数，
只改变未来采样的奖励。运行配置和完整断点记录迁移时间与旧/新系数。

监控中查看 `training/flag_defense_*` 和 `rollout/flag_defense_*`，
战术明细中的 `reward_terms.flag_defense_reward` 是本步真正进入 GAE 的奖励。
即时奖励提高该步回报，但不保证最终标准化优势为正；后续损失仍会影响优势。
