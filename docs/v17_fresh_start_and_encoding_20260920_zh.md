## 坐标与观察者

所有输入使用当前观察者的固定相对视角：自己=0、左家=1、对家=2、右家=3。
其他座位观察同一局时，棋盘位置、棋子归属、上一手行动者、存活位、剩余跳过次数以及当前
行动方一起转换。此编号是空间顺序，不是实际轮流行动顺序。

棋盘固定 129 个位置：0–29 是本方营区，30–59 左家，60–89 对家，90–119 右家，
120–128 中央九宫。每个营区按六行五列排序，第一排靠近中央，包含行营和大本营位置。
中央九宫随观察者旋转。棋子移动后，候选身份和已确认槽号随棋子移动。

## 行动编码：14 → Linear → 128

这是已经发生的上一手行动及其**行动后**规则状态，不是给每个候选动作预先编码未来结果。

| 原始维度（1 起算） | 内容 | 数值 |
| --- | --- | --- |
| 1–2 | 上一手起点 x、y | 全盘相对坐标，原始整数 |
| 3–4 | 上一手终点 x、y | 同上 |
| 5 | 上一手行动者 | 自己/左家/对家/右家为 0/1/2/3 |
| 6 | 无吃子和棋剩余步数 | max(0, 70 − 当前无吃子计数) |
| 7–10 | 四个玩家存活状态 | 自己、左家、对家、右家；存活 1，出局 0 |
| 11–14 | 四个玩家剩余跳过次数 | 相同顺序，各为 0–4 |

没有除以坐标范围、70 或 4；这些值直接经过带偏置的线性层投影为 128 维。
坐标 +x 向右、+y 远离观察者。若某营区格的零基行列为 r、c，令 x=c−2、y=−(r+3)，
四个营区依次转换为 `(x,y)`、`(y,−x)`、`(−x,−y)`、`(−y,x)`。
中央九宫使用 `{-2,0,2} × {-2,0,2}`，整盘坐标范围为 −8 到 8。

初始 token 尚无上一手，前五个值全部置零，但保留当前倒计时、存活位和跳过次数；
正常开局分别是 70、1111、4444。主动跳过时，四个坐标值全部为零，行动者仍为实际座位。
跳过消耗该玩家一次机会，并推进无吃子计数；通常的无损移动也推进计数，交战出现棋子损失则归零。
玩家无棋可动时先按规则出局，不会靠剩余跳过次数继续存活。

不再另外加入无吃子倒计时/存活状态 embedding；剩余跳过次数仅从行动支路进入网络。
当前轮到谁走与上一手行动者是两个不同字段，前者通过后述 `current_player_embedding` 表示。

## 棋盘编码：129 × 26 + 3 = 3357 → Linear → 384

每个位置 26 维；前 25 维为子力槽，末维为归属。槽位是二进制可能性，**不是概率分布**，
不会归一化到总和为 1。同一种棋子的多枚副本使用不同槽，不同玩家分别拥有同一套 25 槽。

| 位置内维度（1 起算） | 内容 |
| --- | --- |
| 1 | 军旗 |
| 2–4 | 三枚地雷 |
| 5–6 | 两枚炸弹 |
| 7–9 | 三名工兵 |
| 10–12 | 三名排长 |
| 13–15 | 三名连长 |
| 16–17 | 两名营长 |
| 18–19 | 两名团长 |
| 20–21 | 两名旅长 |
| 22–23 | 两名师长 |
| 24 | 军长 |
| 25 | 司令 |
| 26 | 单个归属值：自己=1、左家=2、对家=3、右家=4 |

空格全部 26 维为零。棋子归属不是四维独热，而是一个整数。
129 个位置按固定编号展开得到 3354 维，再拼接三维模式独热：四暗 `100`、双明 `010`、
二人 `001`。本次正式训练始终四暗。三维模式位进入棋盘投影，后述模式 embedding 也继续保留。

棋盘线性层有偏置，整体一次投影到 384 维，不是每格先各自变成 384 维。
棋盘几何由位置编号固定；没有额外的道路、铁路、行营、大本营、危险分数或军旗距离通道。
独立的 75 维阵亡输入已经删除，四维跳过次数也不再拼入棋盘。
内部的 0/30/31 等棋盘代码只辅助确定归属、接口和存档，不是额外的 139 类独热输入。

## Actor 的已知身份与未知候选

己方棋子身份完全可知，每枚棋子使用唯一的独热槽。四暗中队友和对手都遵守暗棋可见性；
只有公开揭示或公开证据确定的身份才变成独热。双明模式额外允许看到队友真实身份，当前训练不使用双明。

隐藏玩家第一名被确认的工兵分配 `100`，后来确认为工兵的其他棋子依次分配 `010`、`001`。
同一步有多个新确认时按棋主棋盘位置排序。确认槽号跟随棋子，阵亡后也不重新分配该号。
己方以及双明可见队友采用与真实棋子一致的固定编号；暗棋对手编号只依据观察者合法知识分配。

身份未定的棋子使用多热候选。例如仍可能是工兵、排长的棋子可以同时打开这两类的可用槽。
一枚工兵确认为 `100` 后，同一玩家其他未知子的工兵部分从 `111` 改为 `011`；该工兵之后
阵亡仍保留 `011`，不再扣一次。另一个 `010` 被确认后改为 `001`；全部三个名额被已确认
棋子或确定损失占用后，未知子的工兵部分为 `000`。其他棋种同理。

只知道死亡数量、无法对应已分配编号的损失从最高未分配槽扣减：没有其他已确认编号时为
`111 → 110 → 100 → 000`。它与确定编号占用后的 `011` 表示相同的剩余名额数，但槽号不同；
不能把已有棋子的持久编号重排。规则继续保留未确定身份的损失，不擅自把它们计成某种棋子。

## 规则层如何持续收紧候选

1. 初始布阵约束：第一排排除炸弹；地雷只可能在后两排；军旗只可能在两个大本营。
2. 移动排除军旗和地雷；只有工兵能完成的铁路转弯路径确认工兵。已经得出的约束随棋子移动，
   不会在换格后重新套用该格的出生位置限制。
3. 交战枚举观察者允许的攻守双方棋种组合，仅保留符合胜负/同归于尽、夺旗、司令死亡亮旗
   等公开结果的组合。只有全部可行组合都同意的身份才能确定；尚有多种解释就保留多种候选。
4. 每名玩家的在场和已移除棋子合计 25 个变量，与该玩家初始 25 槽进行可行匹配，排除不能
   出现在任何可行分配中的候选。再计算每种棋子的确定死亡数量下界，更新可用槽。
5. 同归于尽事件保存双方身份配对关系。新证据到来时，历史关系和库存反复传播，直到不能继续
   收紧。例如炸弹名额被其他已知棋子/损失占满后，先前不确定交换可能被确定为同级对掉。
6. 司令死亡后公开军旗位置并更新候选；玩家出局移除其全部棋子，清除相应在场槽并置存活位为 0。

这些是规则生成的公共信息推理，不是神经网络输出。每名观察者独立记账，Actor 不读取裁判
隐藏身份。库存和历史关联随棋局保存/恢复，不因 Transformer 的 1000 步窗口而遗失。
新证据只影响当前和未来 token，已采样的过去 token 不改写。
这里保留的候选及同归于尽关系不等于全部历史交战的完整联合后验。

## Critic 与 Actor 的区别

两者投影形状相同，但输入来源和参数独立。Actor 使用玩家可知的候选；集中式 Critic 使用
所有在场棋子的真实身份，每枚真实棋子占一个持久独热槽。重复棋种仍各占不同槽，死亡后
该棋子消失，存活同类棋子不重编号。Critic 不把真实隐藏身份写回 Actor 历史。
四个玩家分别生成相对视角，玩家出局后仍保留其 Critic 视角；同一个 Critic 网络输出该玩家
的一个 V 值。未来行动和未来结果不进入当前编码。

## 融合、时序和动作输出

```text
上一手行动与当前规则状态 14维 → Linear → 128维 ┐
                                                ├→ 按[行动,棋盘]拼成512维 → SwiGLU
整盘候选、归属、模式 3357维 → Linear → 384维 ┘
→ 加历史位置embedding、模式embedding、当前行动方embedding
→ 16层因果Transformer，8头，每头64维 → 最后一个有效token
```

SwiGLU 将 512 维分别线性投影为 gate 和 value，计算 `SiLU(gate) * value`，再线性投影回
512 维。当前 dropout=0。当前行动方 embedding 取相对座位 0–3，无当前行动方/填充取 4。
没有额外的亮旗 embedding；亮旗造成的身份和候选变化已经进入棋盘。

每次真实棋局行动后生成一个“该行动 + 行动后盘面”的 token，四个玩家各有自己的历史。
模型始终保留初始盘面，并保留最近 1000 个行动 token，最长 1001。因果注意力只能读取过去。
它没有另加独立的绝对棋局步数、has_moved、交战结果枚举或静态道路通道；相关信息由行动历史、
盘面变化、规则推断和合法动作约束共同提供。

Actor 输出先选起点，再把起点的 129 维独热与 512 维上下文拼接，条件化地选终点。
起点头为 512→256→129，终点头为 641→256→129；中间用 SiLU，合法动作外的 logits 屏蔽为负无穷。
合法完整动作概率为 `P(起点) × P(终点 | 起点)`。训练采样依此概率执行；网页可选择联合概率最大动作。
这套预测输出与前述 14 维“上一手行动输入”用途不同。强制炸大子、吃眼前工兵、夺旗的冠军规则
仍未启用，不影响当前动作分布。

原始历史存储为每视角每 token 476 个 int16，包含压缩候选、内部阵亡记账和规则元数据；
它是存储格式，不是网络输入维度。前向路径仅取 v17 的 3357 维棋盘和 14 维行动。
正常前向、数组批处理、增量 KV 和学习路径使用同一语义。
