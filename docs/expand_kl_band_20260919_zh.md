# expand MAPPO 温和学习率调节

2026-09-19 的当前训练采用 KL 保持区间，取代完成三个 epoch 就上调 50%、高 KL 就下调 40% 的方式。

| 本轮最终抽样平均 KL | 行为 |
|---|---|
| 小于 0.08，连续 3 个有效训练轮 | 下一轮实际学习率乘 1.05 |
| 0.08 至 0.14，含边界 | 保持学习率，清空连续计数 |
| 大于 0.14，连续 3 个有效训练轮 | 下一轮实际学习率乘 0.95 |
| 发生实际升降后的 3 轮 | 保持学习率，只观察，不积累下一次调整的计数 |
| 方向反转或没有学习样本 | 清空此前方向的连续证据 |

冷却结束后重新积累连续 3 轮证据。例如第 3 轮提高后，第 4–6 轮完整观察，第 7–9 轮重新确认，最早第 9 轮结束才再次调整。上下限仍为 5e-6 与 1e-4，达到边界后不积累隐藏倍率。Critic 保持既有的 Actor 倍率关系；本次倍率仍为 1。布阵学习率不变。

这里的 KL 是每轮最终模型在 8192 个已采样学习动作上的近似 KL 均值，相对于本轮采样行为策略。它不是相邻两个 epoch 之间的 KL，也不是全动作分布的精确 KL。EMA 继续显示，但连续性判断使用每轮 KL 本身，避免把用户指定的连续三轮变为额外的 EMA 等待。

## 早停与监控

原先小批次 KL=0.1 的保护会提前截断新的均值目标，因此只在启用此区间模式时：

- 每个完整 Actor epoch 结束后，用同一组探针均值检查是否大于 0.14；超限则结束本轮后续 Actor epoch。
- 始终完整处理首遍样本，最多仍为三个 Actor epoch，Critic 仍为三个 epoch。
- 小批次 KL 峰值保留监测，不用于此模式的早停或学习率决策；梯度裁剪和非有限数保护保留。
- 早停控制本轮剩余训练量，连续三轮调节控制下一轮 LR，两者分别生效。一次超限可早停，但不会立即改学习率。

0.14 是检测时的停止阈值，不是任何一个 Adam 更新后 KL 的硬上限。其他配置未启用区间模式时继续采用原先的早停和学习率规则。

监控主卡改为显示最终平均 KL 与 0.08–0.14 保持区间；详情显示连续计数、观察期剩余、上下限、调整幅度及原因。旧记录继续按旧模式显示。

## 配置与恢复

`configs/expand_mappo_training.yaml`：

```yaml
increase_on_full_epochs: false
kl_band_lower: 0.08
kl_band_upper: 0.14
increase_factor: 1.05
decrease_factor: 0.95
stable_updates: 3
cooldown_updates: 3
```

此模式直接控制实际学习率，不叠加预热或余弦变化。初次从旧控制器迁移，保留断点中优化器当前实际 LR，丢弃旧规则尚未应用的下一轮大幅调整，重置不同统计口径的 EMA、连续计数和冷却计数。

后续正常恢复保留新控制器已决定的下一轮 LR、升降方向计数、EMA 和冷却期。控制器状态版本为 2，兼容旧版本 1。模型、优化器矩、RNG、未完成对局、奖励衰减及训练总量按原恢复流程保留。
