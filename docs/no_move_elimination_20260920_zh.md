# 无实际合法行棋动作时直接出局

2026-09-20 修改 expand 分支的共享游戏规则，训练自对弈、评测和 CPU 人机测试新棋局一致使用。

## 规则

轮到一名玩家时，若没有任何实际合法移动或攻击，直接判该席位出局，清除其剩余棋子并检查团队终局。即使还有跳过次数，也不能用跳过延长存活。判断的是实际合法走法，包含只剩军旗、地雷，活动棋子困在大本营，以及全部道路被堵住等情况。

有实际合法走法时，仍保留原来的每人四次主动跳过。出局本身不扣跳过次数，不生成跳过行动、额外环境步或 Actor 样本。阵亡后队友继续作战，沿用此前 Actor/Critic 的虚拟个人回合 GAE。

判定边界是该玩家的回合到达时；其他玩家回合中临时被堵，不会提前出局。这与现有引擎处理无合法动作的时点一致。

原问题在于合法动作列表先放入了 PASS，出局判断看到非空列表就认为玩家仍能行动。现在先生成真实走法，只在真实走法非空时提供主动 PASS。CPU 测试服务也删除了无子可动时自动替玩家跳过的路径。

## 存档与续训

`GameConfig.eliminate_no_moves` 默认开启。旧六字段 GameConfig 存档反序列化后保留旧规则，保证过去的棋谱仍能复现。完整旧训练断点需要一次显式 `--adopt-no-move-elimination`，或执行同一迁移函数并验证后原子替换完整断点；已迁移断点正常启动，无需再次加参数。

本次在第 1246 轮安全停止后迁移，累计环境步 122,486,784。128 个未结束棋局中，没有当前行动席位无子可动的局面，因此仅更新规则字段；完整权重、所有优化器、随机数、控制器、计数、棋盘和历史均经过迁移前后及存盘往返比对。两名非当前席位无子可动的玩家，在后续到达其回合时按新规则处理。

gamma=1.0、lambda=0.95、Actor/Critic 实际学习率各 5e-6，奖励和网络结构保持原值。迁移备份及验证记录在 `output/diagnostics/no_move_elimination_20260920/`，其中 `adoption_receipt.json` 记录原断点哈希与保存结果。

一般迁移也处理当前无子可动的存档：出局后只修正当前最后一帧的 Actor/Critic 输入，保留之前所有帧；若直接结束整局，则记录该局结果并正常补充棋局，不虚构优化样本。此次正式断点未触发这两个分支，测试覆盖了它们。
