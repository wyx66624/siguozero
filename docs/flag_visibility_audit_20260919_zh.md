# 军旗位置推断与司令阵亡亮旗的显示修复

## 真实棋谱结论

检查对象为 four_dark、模型 update 210、种子 759520674 的已结束人机对局，共 126 步。

- 第 87 步后，玩家 0 能通过公开信息确定左方 56 号点是军旗。左方的司令阵亡亮旗状态仍为 `false`。
- 第 122 步，左方从 51 到 53 吃掉玩家 0 的师长。裁判记录中该子确实是司令，玩家观测的司令标注与真实身份一致。
- 旧页面只显示子力名称和可见性，既未传送也未展示军旗位置已知的原因，造成“确定旗位”与“司令阵亡亮旗”的混淆。

## 修复行为

- API 单独提供各相对座位的 `revealed_flags` 和每步的 `newly_revealed_flags`，均来自公开观测。
- 对手军旗由公开信息确定，但未发生司令阵亡亮旗时，棋盘显示 **推断旗**。
- 确实发生司令阵亡亮旗时显示 **亮旗**，悬浮说明明确原因；己方与双明棋可见队友的旗位保持正常显示。
- 旧对局进程若未提供亮旗状态，显示 **已知旗**，不根据可见性推定司令阵亡。刷新页面即可加载显示修复，新开棋局使用完整状态字段。
- 明棋复盘中的裁判身份显示仍为军旗，不当作对局时已经得出的公开推断；新复盘记录保存每步亮旗状态。
