# 重复送子的临时即时惩罚

本地四暗棋 PPO 启用初始幅度 `0.01` 的即时惩罚，帮助模型减少已经有战斗证据的送子行为。
它只作用于后续行棋的策略和价值训练，推理选招和规则引擎的胜负结果不变。

## 触发条件

每个玩家分别记住：某颗仍存活的棋子，曾经战胜的、该玩家当时确知等级的最大普通棋子。
若随后用不高于该已败棋子等级的子攻击同一目标并阵亡，当步奖励减去当前惩罚幅度。
例如军长已经被该目标吃掉，再用师长、旅长或更小棋子撞它会扣分；同等级棋子也已被证明打不过。
目标主动吃子、随后移动、跨采样批次及断点恢复都保留记录；目标被消灭后清除记录。

- 第一次试探未知棋子不罚，不读取对手隐藏的真实等级来决定是否惩罚。
- 炸弹能够交换，故不罚；工兵攻击尚可能是地雷的目标不罚。
- 若目标已经移动或确知不是地雷，且已有更强棋子败给它，工兵再撞也属于确定送子。
- 四暗棋不会把队友私有的棋子等级传给其他席位；双明棋依照原有可见规则共享已知信息。
- 历史模型的动作不产生学习方惩罚。此项不进入布阵回报、棋力测评得分或人机对弈计分。

## 进度与频率衰减

令 `s` 为开始启用时已完成的全局环境步数，`t` 为当前步数，`H = 总目标 / 2`。
当前 30 亿步预算对应 `H = 15 亿步`。恢复已有训练时从启用点开始，以 `0.01` 为初始幅度。

```text
progress_factor(t) = clamp((H - t) / (H - s), 0, 1)
本轮触发率 = 本轮学习方触发次数 / 本轮学习方实际行动数
rate_ema = 0.95 × 旧平滑触发率 + 0.05 × 本轮触发率
reference_rate = 启用后首次非零的平滑触发率
frequency_factor = min(历史 frequency_factor, rate_ema / reference_rate, 1)
penalty(t) = 0.01 × progress_factor(t) × frequency_factor
```

尚未出现非零触发率时，频率因子为 1。系数每个完整训练更新调整一次，只降不升。
如果频率因子不变，从启用点到一半目标的中点幅度为 `0.005`；失误率下降会进一步减小。
全局步数到一半时精确归零。采样批次在此处拆分；多卡无法整分的最后不足一个 rank 组，
最多提前 `world_size - 1` 步停用，不允许惩罚延伸到后半程。
既有扛旗奖励和和棋效用采用各自配置，本项归零不会改动它们。

## 配置、恢复与监控

```yaml
ppo:
  futile_attack_penalty: 0.01
  futile_attack_ema_decay: 0.95
```

其他配置默认关闭。无全局环境步预算的短小测试默认关闭，可显式指定预算和惩罚来验证。
已有训练首次采用此目标，使用 `--adopt-futile-attack-penalty` 从完整 `latest.pt` 恢复。
迁移保留模型、优化器、随机状态、未结束棋局、布局缓冲、已完成测评和历史模型状态；
记录启用步数，后续检查点保存每个玩家的战斗证据、平滑率、频率因子和归零进度。

监控页显示本轮及下轮系数、触发次数、触发率、平滑率、扣分总量与归零步数。
对应指标前缀为 `training/futile_attack_*` 和 `rollout/futile_attack*`。

验证入口：`tests/test_futile_attack_penalty.py`，覆盖公开信息隔离、首次试探、移动目标、
工兵/炸弹例外、三种采样路径、终局奖励叠加、GAE 阵营符号、进度归零及完整断点恢复。
