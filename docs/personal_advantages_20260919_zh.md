# expand MAPPO：每个玩家独立的动作优势

按用户要求，四名玩家继续共享队伍的终局胜负，但每个实际动作使用该玩家自己的 Critic 视角、
奖励和决策轨迹计算优势。0 号的动作不使用 2 号的优势，反之亦然。

## 实际训练口径

配置为 `mappo_advantage_mode: player_decisions`、`mappo_reward_scope: player`。
Critic 保持一个共享参数、单输出的网络，分别读取四个玩家的全知相对视角。
Actor 始终只读取行动玩家的私有观察，没有新增裁判信息或绝对座位 embedding。

从玩家 i 的本次个人回合到下一次实际或虚拟个人回合，累计属于 i 的奖励，使用该玩家视角的价值 bootstrap。
gamma=1 按环境步计算；lambda=0.95 每次个人回合应用一次。两个个人边界之间的价值项相消。
同队终局结果相同不等于动作优势相同：行动发生在不同状态，各自的基线、局部回报和后续决策不同。

### 2026-09-19 Actor / Critic 阵亡后虚拟回合

Actor 与 Critic 已同步采用虚拟个人回合，gamma=1、lambda=0.95 以及奖励配置均不变。
玩家阵亡后，按原始座位顺序 `0→3→2→1→0` 保留个人回合边界；每次原本轮到该玩家时，
以该玩家的全盘 Critic 估值衔接回传，后续 TD 残差尾项乘一次 0.95。上家也阵亡时仍沿
座位顺序经过这些位置，不能简单按固定的四个真实动作计一次。

虚拟回合参与 Actor 的 GAE 和四视角 Critic 目标，不产生实际动作、额外策略样本或棋谱历史；个人出局不截断
团队回报。整局终局清零后继项，采样批次截断继续 bootstrap。环境一步中的无棋可走自动
出局按原子操作处理，所有被跳过座位使用该步处理完成后的盘面。

Critic 的四视角标签为各自的 `V_old + 原始 GAE`，包括阵亡后的局面；Actor 标准化不改变
这些标签。gamma=1 时，相邻个人边界间可写成 `Y_k = R_k + 0.05*V_old(S_next) + 0.95*Y_next`；
终局后继项归零，奖励本身不再额外乘 lambda。网络、带裁剪平方误差和优化器保持原样。
此前“只改 Actor”阶段保留了旧 Critic 标签，此阶段已完成同步。战术日志独立保存 Actor
标准化前的原始优势及双方的时间口径；回放核验兼容原版、只改 Actor 和同步后的三类日志。

## AI 对玩家身份的输入

训练器和环境明确保存绝对编号 0、1、2、3，用来对应这次个人优势。
模型输入采用相对视角：自己为 0、对家队友为 2、另两位是对手。
历史编码含相对行动者、当前轮到谁、四人存活状态，网络实际消费这些字段。
开局 token 被保留且当前训练固定绝对 0 号先手，因此还存在可推知绝对行动顺序的信息。
这说明信息提供到了网络，不证明当前模型已经准确理解和使用全部字段。

## 解释边界

个人优势并不保证“炸掉大子必定正优势”。优势比较这次行动后的回报与该玩家当时的价值基线，
未来团队败局、bootstrap 误差仍可能影响符号。lambda 改为按个人决策衰减后，终局影响可以
传播更远，也可能增加目标方差。需要看新目标下的价值拟合和实际战术回放，不能把迁移成功、
KL 合理或同批次 MSE 下降当作棋力改善证明。
