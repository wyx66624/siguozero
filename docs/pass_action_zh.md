# 每人四次主动跳过与保留进度续训

revision 25（2026-09-12）在四暗、双明和双人规则中加入主动跳过。

- 联合动作编号 `0`、端点对 `(0, 0)` 都表示跳过。棋盘点 0 的其他合法移动保持原意。
- 每人每局初始 4 次，独立扣减且不会补充。剩余 0 次时，规则拒绝跳过，策略掩码将其概率设为 0。
- 跳过不移动、不攻击，也不增加任何棋子身份信息；推进回合，计一个环境交互步，同时增加无吃子计数。连续 70 步没有棋子被移除仍自动和棋，和棋终局训练奖励仍为 -0.15。
- 无合法移动但仍有跳过次数的玩家可以跳过；两者都用尽才按无合法动作出局。

棋盘线性输入尾部增加四个原始整数：自己、相对座位 1、对家、相对座位 3 的剩余次数，范围 0–4。双人模式后两项填 0。四暗含死规则的输入从 18009 维变为 18013 维；Policy 与 Critic 都能读取这四项。历史缓存键也包含剩余次数，防止相同棋盘、不同跳过机会共用错误缓存。

动作历史仍是六维。跳过写为 `[0,0,0,0,actor,remaining_draw_plies]`，初始状态通过独立的动作存在标记区分。并行环境、紧凑历史、完整存盘和 CPU 对弈均使用这一约定。生产策略复用起点/条件终点头，掩码中特别允许或禁止 `(0,0)`；无需增加 Transformer 层。四国静态动作总数 5625，双人 1177，普通移动的联合编号相对旧版顺延 1，端点编号不变。
