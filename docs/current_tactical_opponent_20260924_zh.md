# 当前模型战术对手作为历史池成员

2026-09-24：在 expand 四暗训练的历史池中增加一个 `live_current_tactical` 身份。
它使用当前学习模型，并在每轮 rollout 开始前将 Policy / Layout 复制到已有的冻结对手副本。
同一轮采样中权重固定；下轮可以更新权重，但统计身份、失败率 EMA 和抽样权重连续保留。
不会为每个当前模型 update 新增一个历史条目，也不会将它加入独立的冻结模型棋力评测。

## 抽样和更新

遵循用户最终要求“也按照历史概率分析来进行更新，他就当做是其中一个历史模型”。
初始当前学习队失败率与新历史版本相同，均为 0.5；不是固定 10% 通道，也不是永久等概率。
普通历史版本与这个战术对手共用同一个 strength sampler：

```
L_i ← 0.99 × L_i + 0.01 × 1[当前学习队失败]     # 仅胜负局更新；和棋只计数
p_i = softmax(L_i / 0.10)
```

因此尚未交手且初值相同时，每个池成员等概率；实际交手后，当前学习队越容易输给某个对手，
该对手越常被采到。当前版本更新不清空战术对手的 EMA。

保留原 10 亿环境步启用门槛和启用后的 80% 当前自博弈 / 20% 历史池目标。
新对手从历史池份额中抽取，绝对开局目标为 `20% × p_i`。
沿用单驻留副本和 cohort 调度；这是长期配额目标，不代表每个 rollout 恰好满足比例。

## 强制规则及顺序

1. **解除一步夺旗威胁**：本方军旗受到公开可确认的一步吃旗威胁时，
   在合法且可确认吃掉或兑掉攻击者的己方棋子中选军阶最大的。
   普通棋子无法解决而炸弹可以时使用炸弹；没有可确认成功的吃法时，仍用最大的合法攻击者尝试防守。
2. **炸明大子**：炸弹可以合法攻击公开确认的师长、军长、司令时必须炸。
3. **吃工兵**：可以合法吃掉或兑掉公开确认的敌工兵时必须执行，包含铁路转弯后已确认身份的工兵。
4. **白吃**：所有公开候选身份下都能吃下且己方存活，并且吃后没有公开可确认的立即反吃威胁。
   隐藏威胁仍可能存在，此规则不声称保证整盘收益。

同一优先级有多个候选时，由当前模型在候选集合内采样。其余局面完全沿用原模型采样。
高优先级守旗与炸大子同时出现时先守旗。
所有规则只读取该席位的 Actor 观测、公开候选身份、存活状态、棋盘几何和合法动作，
不读取裁判暗棋身份或 Critic 的全局信息；行营、敌友关系和铁路阻挡仍遵守原棋规。

## 学习与续训

战术对手的动作保持 `learnable=False`，不将强制动作伪装成当前学习方采样来计算 PPO。
学习方继续从自己的动作与真实对局后果学习；Critic 仍保留其原有四视角标签。
本次不修改奖励、优势计算、PPO 损失、熵系数、学习率或 minibatch。

检查点持久化新规则契约、固定身份战绩、EMA、抽样 RNG、cohort 和触发次数。
启用前尚未使用历史池的检查点可沿用现有恢复机制采纳新契约；已使用历史池的检查点
不能静默切换规则。保留全部真实历史文件；虚拟成员不会触发历史文件读取或预取。

仪表盘单列“当前模型 + 战术规则 · 单一身份”，显示它的抽样概率、胜和负和规则触发次数。
在 10 亿步之前，配置已加载但实际触发次数为零，不表示训练已经体验了这种对手。
